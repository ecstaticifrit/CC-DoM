## Agent skills

### Issue tracker

Track specs and tickets as local markdown under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels in each implementation ticket's `Status:` line. See `docs/agents/triage-labels.md`.

This repo uses a single-context layout: `GLOSSARY.md` and `docs/adr/`. See `docs/agents/domain.md`.

### Collaboration

Claim tickets, branch and merge as described in `docs/collaboration.md`. The feature spec is `.scratch/friday-payment-run/spec.md`.
