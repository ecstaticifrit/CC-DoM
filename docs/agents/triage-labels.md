# Triage labels

Use the local status string when a skill names a triage role.

| Canonical role | Local status string | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the ticket. |
| `needs-info` | `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | `ready-for-agent` | An agent can implement the ticket without further input. |
| `ready-for-human` | `ready-for-human` | A human needs to implement the ticket. |
| `wontfix` | `wontfix` | The maintainer will not pursue the ticket. |
